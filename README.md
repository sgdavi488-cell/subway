# 🇧🇷 Brasil Rush

Um endless runner independente com clima brasileiro, feito com HTML, CSS e JavaScript puro.

## Como jogar
- **A / D:** trocar de pista
- **W:** pular
- **S:** deslizar
- **Celular:** arraste o dedo na direção desejada ou use os botões na tela.

## Objetivo
Desvie dos obstáculos, pegue moedas e aumente sua pontuação. O contador **Sem moedas** mostra quanto tempo passou desde a última moeda coletada — ele reinicia quando você pega outra.

## Personagens
Neymar Jr., Anitta, Vini Jr. e Rayssa aparecem em versões gráficas simples e estilizadas, como referências de entretenimento. Projeto independente, sem associação ou endosso das pessoas retratadas.

## Tecnologias
- HTML5
- CSS3
- JavaScript
- Canvas API
- LocalStorage para salvar o recorde no navegador

## Executar
Abra o arquivo `index.html` no navegador ou publique pelo GitHub Pages.

Projeto de estudo e portfólio. Os gráficos são originais e não utilizam arquivos ou recursos oficiais de Subway Surfers.
